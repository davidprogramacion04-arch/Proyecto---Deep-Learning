# Proyecto - Deep Learning

Espacio compartido para desarrollar el proyecto de Deep Learning en equipo.

## Organización sugerida

- `codigo/`: notebooks y scripts.
- `datos/`: bases de datos y archivos de entrada.
- `modelos/`: modelos entrenados y configuraciones.
- `documentacion/`: apuntes, decisiones y resultados.

## Trabajo colaborativo

Antes de comenzar a trabajar, actualicen su copia local:

```bash
git pull
```

Después de realizar cambios:

```bash
git add .
git commit -m "Describe brevemente el cambio"
git push
```

Eviten subir contraseñas, tokens o archivos muy pesados sin acordarlo previamente.
