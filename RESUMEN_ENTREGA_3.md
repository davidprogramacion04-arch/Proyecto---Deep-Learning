# Entrega 3 — resumen

Proyecto de pronóstico horario de PM2.5 para la estación Fontibón (Bogotá). La entrega compara modelos base y LSTM con variantes STN entrenadas desde cero o mediante transferencia desde Beijing, usando evaluación común, tres semillas y auditoría de errores y explicabilidad. Incluye notebooks, código, resultados, figuras y modelos entrenados.
